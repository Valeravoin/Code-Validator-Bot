# Code Validator Bot 🤖🔍

Telegram-бот для валидации промокодов. Проверяет формат, отсекает запрещённые слова, собирает статистику по валидным кодам.


---

## ✨ Возможности

- ✅ Проверка формата: только латинские буквы и цифры.
- ✅ Длина ровно 8 символов.
- ✅ Код не начинается с цифры.
- 🚫 Отсечение кодов с запрещёнными подстроками (`spam`, `hack` и т.д.).
- 📊 Простая статистика: сколько валидных кодов, какие буквы чаще стоят в начале.
